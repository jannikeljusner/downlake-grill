# Downlake Grill & Bar - Projektuppgift DT224G

Detta är slutprojektet i kursen Introduktion till webbutveckling med HTML, CSS och JavaScript vid Mittuniversitetet. Projektet är en responsiv webbplats för restaurangen Downlake Grill & Bar, byggd utifrån konceptet "Mobile First". Hemsidan använder JavaScript och Fetch API för att dynamiskt läsa in menyn från en extern JSON-fil.

**Länk till publicerad webbplats:**
https://jannikeljusner.github.io/downlake-grill/

**Innehåll i detta repository:**

- Källkod (HTML, CSS, JS)
- Wireframes och designskisser (i mappen /design)
- Projektrapport (PDF) (i mappen rapport)
